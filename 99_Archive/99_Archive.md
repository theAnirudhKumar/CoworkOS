# 99_Archive

A folder for old files that are no longer current, such as a retired folder or a superseded draft. It is not a workstation, and nothing here is read at session start.

Move a file here only after the user confirms it is no longer current. Keep its original name, including any date prefix, so other files that mention it still make sense. Add one line to `ARCHIVE.md` for anything important that moves here.

This folder holds old files. The history of what was done lives in `ARCHIVE.md`, not here.
