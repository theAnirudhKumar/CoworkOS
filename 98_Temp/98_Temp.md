# 98_Temp

A holding folder for files whose home is not clear yet. It is not a workstation, and nothing here is permanent.

`Inbox.md` in this folder is the quick-capture list: one dated line per thought, written the moment the user says "jot this down" or shares something with no clear home. The weekly review empties it. `Phone Inbox.md` is the same idea for captures sent from a phone; only the phone adds to it (see 00_Resources/Mobile Capture Guide.md).

Put a file here only when you cannot tell which workstation it belongs to. Give every file a date prefix, `YYYY-MM-DD-descriptive-name`, so its age is visible at a glance.

Review this folder once a week. Move each file to the workstation it belongs to, or to `99_Archive/` if it is no longer needed. Ask before deleting anything.
