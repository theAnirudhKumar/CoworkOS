# Calendar

*An example rulebook. The rules below are samples to show the format. Replace them with your own, or delete this file if you do not use a calendar connector.*

- Reading the calendar needs no permission.
- When creating an event, the default length is 45 minutes unless the user gives one.
- Check for a clash before creating an event, and tell the user if there is one.
- Never accept, decline, move or cancel an event that other people can see without a yes from the user.
- Dates and times are in the user's own time zone, as recorded in Core Memory in root MEMORY.md.
